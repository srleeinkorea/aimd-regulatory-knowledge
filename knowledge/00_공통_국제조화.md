# 공통 기반 — 국제 조화

기준일: 2026-10-22

## 개념
| 용어 | 뜻 | 예시 |
|---|---|---|
| SaMD | 하드웨어 없이 소프트웨어만으로 의료 목적 수행 | 흉부 X선에서 결절 위치를 표시하는 앱 |
| SiMD | 의료기기 하드웨어 안에 들어간 소프트웨어 | 인슐린 펌프 제어 펌웨어 |
| AI-MD / AI-SaMD | 머신러닝 등 AI를 쓰는 의료기기 SW | 심전도로 부정맥 분류 |
| 잠금형(locked) vs 적응형(adaptive) | 출시 후 모델이 바뀌는지 여부 | 적응형은 변경관리계획 필요 |
| 변경관리계획 (PCCP) | 미리 승인받은 범위 안의 모델 변경은 재허가 없이 반영 | 재학습 데이터 추가, 임계값 조정 |

## 국제 문서 (IMDRF)
- SaMD 위험 분류 프레임워크(정보의 중요도 × 환자 상태 심각도) — 한국·싱가포르·일본 분류의 바탕.
- SaMD 임상 평가(N41): 타당한 임상 연관성 → 분석적 검증 → 임상적 검증 3단계.
- GMLP(Good Machine Learning Practice) 10원칙 — FDA·Health Canada·MHRA 공동, 이후 IMDRF 최종 문서화. [확인 필요: IMDRF 최종판 번호]
- MDSAP — 미국·캐나다·브라질·호주·일본 공동 품질 심사. 싱가포르·한국은 참관/연계 수준.

## 재사용 전략 요점
- 품질문서·위험관리·SW 문서는 한 번 만들어 5개국 공용으로.
- 임상 성능 데이터는 다기관·다인종 구성이면 재사용성이 높음 (일본·싱가포르는 자국 인구 적합성 질문이 잦음).
